快速入门

如何开始使用 Chrome-ARF？

只需三步即可开始：

  1. 运行 python refresh_web.py
  2. 在浏览器打开 http://localhost:5000
  3. 点击「启动调试Chrome」按钮

程序会自动启动 Chrome 并连接到调试端口。

刷新间隔可以设置多少？

支持的范围：5秒 到 3600秒（1小时）

常用预设：30秒、1分钟、5分钟、10分钟

也可以直接输入自定义数值。

如何刷新指定的标签页？

Chrome-ARF 会自动刷新当前获得焦点的标签页。

切换到你想刷新的标签页，程序会自动识别并刷新它。

故障排除

Chrome 启动失败

可能的原因及解决方案：

  • Chrome 未安装：请先安装 Google Chrome 浏览器
  • 端口被占用：关闭占用 9222 端口的程序，或程序会自动切换端口
  • 权限不足：以管理员权限运行程序
  • 已有 Chrome 实例：关闭所有 Chrome 窗口后重试
无法连接到 Chrome

请按以下步骤排查：

  1. 检查 Chrome 是否以调试模式启动（任务管理器中应有 --remote-debugging-port 参数）
  2. 检查防火墙是否阻止了本地连接
  3. 尝试更换端口（点击「启动调试Chrome」会自动尝试其他端口）
  4. 重启程序后重试
刷新不生效

可能的原因：

  • 标签页已关闭：刷新的标签页已关闭，请切换到新标签页
  • 页面限制：某些页面可能阻止了程序化刷新
  • WebSocket 断开：点击「停止」后重新「开始刷新」
  • Chrome 崩溃：重新启动 Chrome 调试实例
页面显示异常

尝试以下解决方案：

  • 清除浏览器缓存（Ctrl + Shift + Delete）
  • 使用 Chrome/Edge/Firefox 等现代浏览器访问
  • 检查 JavaScript 是否被禁用
  • 刷新页面（F5）

技术说明

什么是 CDP？

Chrome DevTools Protocol (CDP) 是 Chrome 浏览器提供的调试协议。

它允许程序化控制浏览器，包括：

  • 获取页面信息
  • 执行 JavaScript
  • 控制页面导航
  • 监控网络请求

Chrome-ARF 使用 CDP 的 Page.reload 命令实现刷新功能。

数据安全吗？

完全安全。

  • 所有通信仅在本地进行（127.0.0.1）
  • 不收集任何用户数据
  • 不连接外部服务器
  • 使用独立的调试配置文件，不影响正常 Chrome 数据
支持哪些操作系统？

Chrome-ARF 支持：

  • Windows - Windows 10/11
  • macOS - macOS 10.15+
  • Linux - Ubuntu/Debian/CentOS 等主流发行版

需要 Python 3.6+ 和 Google Chrome 浏览器。
